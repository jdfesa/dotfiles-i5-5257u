# Maintenance tools

- `link-user-config.py`: plan, aplicación y rollback por manifiesto.
- `sync-to-host.py`: sincronización SSH/rsync con verificación de fuentes.
- `check-repository.py`: validación estática del árbol y, opcionalmente, historial.
