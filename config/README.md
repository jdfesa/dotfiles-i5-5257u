# Configuration sources

Cada componente tiene su carpeta. Los destinos del home se declaran en
`manifest.json` y se enlazan desde `/home/jd/dotfiles-i5-5257u`.
`packages/debian.txt` define dependencias directas del perfil principal.
`xfce/` contiene un perfil de recuperación opcional e independiente.
