# Runtime scripts

Helpers de sesión, barra, red y menús. `xfce/` pertenece únicamente al perfil
opcional de recuperación; no se inicia desde Sway.
Los lanzadores de [XAMPP and Composer setup](../docs/others/xampp-setup.md)
también son opcionales y tienen su propio manifiesto.

[Wi-Fi hotspot](../docs/wifi/hotspot.md) añade solo un lanzador bajo demanda.
